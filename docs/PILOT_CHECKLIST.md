# Pilot Checklist (2-3 Restaurants)

## Pre-pilot
- [ ] Production hosting deployed with HTTPS.
- [ ] Database backups scheduled and tested.
- [ ] Monitoring and alerts configured.
- [ ] `SESSION_SECRET` set to a strong random value.
- [ ] CORS origins restricted to production frontend.

## Per restaurant
- [ ] Owner account registered.
- [ ] Restaurant created.
- [ ] Menu categories and items entered with MMK prices.
- [ ] Tables created and QR codes printed.
- [ ] Staff accounts added with appropriate roles.

## Validation
- [ ] Customer can scan QR and place an order.
- [ ] Staff can accept, prepare, and complete orders.
- [ ] Cash payment recorded and appears in history.
- [ ] Wallet payment recorded and confirmed manually.
- [ ] Daily sales report totals match orders.
- [ ] Cross-tenant access verified as blocked.

## Sign-off
- [ ] Restaurant owner confirms usability.
- [ ] Issues recorded and triaged.
